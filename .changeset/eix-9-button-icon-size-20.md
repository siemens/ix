Default icon glyphs are now `20` instead of `24` when `size` is omitted on **ix-icon-button**, **ix-icon-toggle-button**, and nested icons that follow that default. Size `20` is a new public option (32×32 control, 20px glyph); set `size="24"` to keep the previous glyph size.

Leading and trailing icons on **ix-button** and **ix-toggle-button** use size `20`. Labeled **ix-dropdown-button** and **ix-split-button** leading icons use size `20`; the dropdown chevron stays `24`. Icon-only dropdown buttons use size `24` (32×32 host). **ix-dropdown-item** leading icons and submenu chevrons use size `20`; the checkmark stays `16`. **ix-select** and **ix-date-dropdown** triggers use the 20px default where they follow button/icon-button; the select clear button stays `16`. Date, time, and datetime field calendar/clock icons stay `16`. **ix-date-picker** month arrows use the 20px icon-button default. **ix-chip** leading icons use size `20`; the close icon stays `16`. **ix-pill** leading icons stay `16`. **ix-badge** label icons stay `16`; status icons use size `20`. **ix-blind** collapse chevron and leading header icons use size `20`. **ix-message-bar** status icons and the dismiss button use size `20`. **ix-event-list-item** chevrons use size `20`. **ix-breadcrumb-item** leading icons use size `20`; the chevron stays `16`. **ix-card-list** header chevrons use the 20px icon-button default; the overflow more-cards icon stays `32`. **ix-card-accordion** chevrons use size `20`. **ix-group** expand chevrons use size `20`; the context-menu button uses the 20px icon-button default; **ix-group-item** leading icons stay `16`. **ix-key-value** leading icons use size `20`. **ix-pane** collapse/close and heading icons use size `20`. **ix-tree-item** expand chevrons use size `20`. **ix-upload** status icons use size `20`. **ix-workflow-step** step icons use size `20`. **ix-checkbox** and **ix-radio** controls use size `20` (24×24 hit area; the checkbox check stays `18`; the radio inner dot stays `8`). **ix-range-field** delimiter icons use size `20`. **ix-avatar** stays `32`. **ix-tooltip** title icons stay `16`. **ix-link-button** icons stay `16`. **ix-pagination** prev/next buttons use the 20px icon-button default. **ix-flip-tile** flip buttons use the 20px icon-button default. **ix-popover-header** title and close icons use size `20`. **ix-toast** status icons stay `24`; the close button uses the 20px icon-button default. **ix-chat-input** send uses the 20px icon-button default. **ix-category-filter** and **ix-dropdown-quick-actions** actions follow the 20px icon-button default. **ix-application-header** app-switch uses the 20px icon-button default; overflow stays `24`. **ix-content-header** back uses the 20px icon-button default. **ix-menu-item** leading icons stay `24`; **ix-menu-category** leading icons use size `20` and the chevron stays `24`. Menu expand (lg/md) and the small-viewport app-switch stay `24`. **ix-menu-about**, **ix-menu-settings**, and **ix-menu-about-news** close buttons use the 20px icon-button default. **ix-tab-item** labeled icons stay `16`; icon-only tabs stay `24`; rounded tabs stay `32`. **ix-modal-header** title icons stay `32`; the close button uses the 20px icon-button default.

See `BREAKING_CHANGES/v6.md` for migration guidance.

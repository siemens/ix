Add `ix-list` and `ix-list-item` for keyboard-navigable lists with standard or custom item content, controlled checkbox selection, configurable variants, dividers and spacing, trailing actions that can appear on hover or focus, and opt-in pointer and keyboard reordering with dynamic or separator feedback and order-change notifications.
Add `ix-list-item-separator` as a standalone full-width list separator that uses the same divider style as `ix-list-item` and participates in spacing configured by `ix-list item-gap`.

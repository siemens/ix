Add the `.ix-visually-hidden` and `.ix-visually-hidden-focusable` CSS utilities. `.ix-visually-hidden` hides content visually while keeping it in the accessibility tree, for example a table caption or extra context inside a link. `.ix-visually-hidden-focusable` stays hidden until it receives focus, which allows a "skip to main content" link to be built on top of it.

Fixes #2922

Use `--si-ref-typography-font-family-mono` for native `<pre>`, `<code>`, `<kbd>`, and `<samp>` elements in the reset, globals, and legacy stylesheets. The classic theme's monospace font now defaults to `'Courier New', monospace` instead of the legacy `'JetBrains Mono'`.

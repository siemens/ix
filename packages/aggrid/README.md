# Siemens Industrial Experience - Theme for AG Grid

This library is part of the Siemens Industrial Experience mono repository.
You can find the root README [here](https://github.com/siemens/ix/blob/main/README.md)

The theme uses IX design tokens for checkbox corner radii and focus indicators.
Keyboard-focused checkboxes display one offset focus ring; cell and header focus
rings are drawn inside their bounds to remain visible within the grid.

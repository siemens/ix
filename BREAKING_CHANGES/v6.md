# Breaking Changes V6

This document lists breaking changes introduced in Siemens Industrial Experience V6.

## Date Time Picker

**Locale support** - locale support was extended to date-time values and headers, so the return value strings will now be localised. 

Note: we have introduced ISOxxx (e.g. `ISOFrom`) fields which hold the backward-compatible locale-neutral values, i.e. the values `from` and `to` held prior to this update.

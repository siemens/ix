# Breaking Changes V6

This document lists breaking changes introduced in Siemens Industrial Experience V6.

## Date Time Picker

**Locale support** - locale support was extended to date-time values and headers, so the return value strings will now be localised. 

Use the new `isoFrom`, `isoTo`, and `isoTime` fields for locale-independent ISO 8601 values. These fields use standardized ISO formatting rather than preserving the previous custom `from`, `to`, or `time` strings.

# ix-layout-grid

> Column-based grid layout for arranging content responsively.

- Web component: `<ix-layout-grid>`
- React/Vue: `IxLayoutGrid` from `@siemens/ix-react` / `@siemens/ix-vue`
- Angular: `<ix-layout-grid>` (`IxModule` from `@siemens/ix-angular` or `IxLayoutGrid` from `@siemens/ix-angular/standalone`)

## Documentation

- https://ix.siemens.io/docs/components/layout-grid/guide.md

## Figma IDs

## Properties

- `columns`; attr: `columns`; type: `number`; default: `12` - Overwrite the default number of columns. Choose between 2 and 12 columns.
- `gap`; attr: `gap`; type: `"12" | "16" | "24" | "8"`; default: `'24'` - Grid gap
- `noMargin`; attr: `no-margin`; type: `boolean`; default: `false` - The grid will not have any horizontal padding
